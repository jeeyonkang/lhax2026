# 집계 기준 — 하자 접수대장 week1 (A-M2-01)

> [가상 자료] 대상 자료는 실습용 가상 정보입니다.
> 원본 `inputs/m2/A-M2-01_하자접수대장_week1.csv`는 수정하지 않는다. 행 번호는 머리행을 뺀 데이터 행 번호(1부터)다.
> 기준은 집계 전에 정하며, 결과를 보고 기준을 바꾸지 않는다. 바꿀 때는 이 파일의 "변경 이력"에 남긴다.

## 1. 검사 순서

앞 규칙에서 제외된 행은 뒤 규칙을 적용하지 않는다. 순서를 바꾸면 결과가 달라지므로 이 순서를 지킨다.

1. R1 합계·소계 행
2. R2 접수번호 완전 중복
3. R3 내용 중복(접수번호만 다름)
4. R4 위치코드 표기 표준화
5. R5 면적단위 환산
6. R6 필수값·허용값 점검
7. R7 집계 후 대조(합계 행·공개 기대값)

순서의 이유: 합계 행과 중복을 먼저 걸러야 고치는 작업과 면적 환산이 불필요한 행에 쓰이지 않는다. 위치코드를 R3보다 먼저 표준화하면 표기 차이로 중복을 놓칠 수 있으나, 이 기준에서는 위치코드를 고치기 전 원문으로 먼저 비교하고 R4 이후 표준형으로 한 번 더 비교한다(R3 비고).

## 2. 규칙표

|---|---|---|---|---|

| R6c | 허용값 위반 | 공종이 마감·창호·설비·전기·방수결로가 아님 / 긴급구분이 긴급·일반이 아님 / 처리상태가 접수·처리중·완료가 아님 / 접수일이 2026-10-26~10-30 밖 | 제외하지 않고 보류 | `run_log.md` ({확인 필요: 항목}) |

## 3. 항목별 세부 기준

### 위치코드(R4)
- 표준형은 `동-호-공간`이다. 동은 3자리, 호는 3~4자리, 공간은 한글 표기다.
- `110동 501호 안방`처럼 구분자만 다른 경우는 숫자와 공간을 그대로 옮겨 `110-501-안방`으로 고친다.
- `111-603 욕실`처럼 공백 구분이면 `111-603-욕실`로 고친다.
- `111301`처럼 구분자와 공간이 없는 경우, 동·호는 숫자를 3자리와 나머지로 나눈다. 공간은 하자내용에 공간 단어가 있으면 그 단어를 쓴다. 근거는 `run_log.md`에 적는다. 내용에도 공간이 없으면 공간 부분을 {확인 필요: 공간}으로 둔다.
- 하자내용 안에 적힌 다른 호수(예: `아래층 1104호`)는 위치코드를 바꾸지 않는다. 한 접수번호는 1건으로 센다.

### 중복(R2·R3)
- 같은 건으로 보는 기준은 R2는 전 열 일치, R3은 접수일·위치코드·공종·하자내용 일치다.
- R3은 같은 날 같은 곳에 같은 증상이 두 번 접수된 경우이므로 재접수와 구별되지 않는다. 이 기준은 먼저 제외하고 기록하되, 현장에서 별개 건으로 확인되면 되돌린다. 되돌릴 때는 `excluded_rows.csv`에서 해당 행을 빼고 `run_log.md`에 변경 이력을 남긴다.
- 위치코드를 고친 뒤(R4) 표준형으로 한 번 더 R3을 적용한다. 새로 걸린 행은 같은 방식으로 제외한다.

### 면적(R5)
- 환산 기준은 1평 = 3.3058㎡(가상주택공사 하자관리 기준(가상))다.
- 행별 환산값은 반올림하지 않는다. 포함 행의 ㎡ 값을 모두 더한 최종 합계에서 한 번만 사사오입해 소수 1자리로 맞춘다. 사사오입은 파이썬 `round`가 아닌 `Decimal`의 `ROUND_HALF_UP`으로 한다.
- 합계 행(R1)의 면적은 더하지 않는다.

### 건수
- 정상 건수는 R1~R3에서 제외되지 않은 행의 수다. R4~R6은 행을 제외하지 않으므로 건수를 바꾸지 않는다.
- 공종별·처리상태별·긴급 건수는 정상 건수 대상 행으로만 센다.

## 4. 기록 파일 형식

`outputs/m2/excluded_rows.csv` 열:

| 열 | 내용 |
|---|---|
| 원본행 | 데이터 행 번호(머리행 제외, 1부터) |
| 사유 | 규칙ID와 사유(중복이면 남긴 행 번호 포함). 예: `R2 완전중복(남긴 행 31행)` |
| 원본값 | 원본 행의 9개 열을 `\|`로 이은 값 |

`outputs/m2/run_log.md`에는 규칙별로 행 번호, 원본 값, 처리 결과, 근거를 적는다. 근거 위치는 `A-M2-01 12행`처럼 쓴다.

## 5. 이 기준을 week1 대장에 적용하면(원본 점검 결과에서 예상)

원본을 읽어 점검한 결과이며, 스크립트로 확정하기 전의 예상이다.

| 규칙 | 해당 행 | 처리 |
|---|---|---|
| R1 | 45 | 제외 |
| R2 | 32 (31행과 동일) | 제외 |
| R3 | 40 (38행과 동일) | 제외 |
| R4 | 2, 16, 21 | 고쳐서 포함 |
| R5 | 8, 13, 22, 26 | 환산해서 포함 |
| R6a·R6b | 해당 없음(마감·방수결로 면적 누락 없음) | - |

예상 정상 건수는 45 − 3 = 42건이다. 검산표 공개값은 41건이므로 1건이 차이 난다. 이 기준만으로는 차이 1건의 행을 정할 수 없다. {확인 필요: 41건이 되도록 추가로 제외할 행과 그 사유} 값을 맞추기 위해 임의로 행을 제외하지 않는다.
