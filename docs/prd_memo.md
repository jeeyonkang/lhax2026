# PRD 메모 (월 환경 세팅)

| 항목 | 내용 |
|---|---|
| 문제 | 여러 경로 접수분을 손으로 합친 하자 접수대장에서 중복·단위 섞임·합계 행을 눈으로 걸러 세다 보니, 매주 건수와 면적이 틀려 회의에서 수치를 다시 고친다 |
| 쓰는 사람 | 하자관리팀 접수대장 담당자 (매주 월요일 오전, 지난주 대장으로 집계 결과를 회의 자료·협조전에 넘기는 사람) |
| 확인 방법 | 검산표 공개 정상 건수와 일치하는가(예/아니오), 제외·수정 행마다 사유와 원본 값이 남았는가(예/아니오), 보수 면적 합계가 직접 계산한 값과 같은가(소수 1자리, 차이 0.0㎡) |
